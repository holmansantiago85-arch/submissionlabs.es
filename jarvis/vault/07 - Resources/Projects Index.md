# Projects Index

Local project folders Jarvis can read and work in, and what each is. Jarvis maintains this list. Access comes from `extra_dirs` in the voice config and from opening Claude Code in the folder.

## Projects
- `~/submissionlabs.es` — the Submission Labs repository. Holds the Jarvis bundle in `jarvis/`. Site source when it is added.

## Add a project
Run `./link_projects.sh /path/to/folder` from the jarvis folder, or tell Jarvis "add this folder to my projects". Jarvis adds a line here with one sentence on what it is.
